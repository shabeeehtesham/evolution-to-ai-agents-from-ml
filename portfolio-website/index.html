01

Multi-Layer Perceptron

Foundations & Backpropagation

Feedforward network processing inputs through dense linear transformations and activation functions. Backpropagation calculates loss gradients using matrix calculus to adjust weights.

  • Vectorized Forward & Backward
  • Sigmoid, ReLU, Softmax
  • NumPy Only Implementation
🔄
02

Recurrent Networks

Sequential Memory & Loops

Introduces recurrent feedback loops ($h_t$) to process sequences of arbitrary length. LSTMs solve vanishing gradients by gating information flow via internal cell states ($c_t$).

  • Character-level language modeling
  • Gated forget/input/output cells
  • Temperature-scaled generation
⚡
03

Self-Attention Models

Parallel Context Mapping

Replaces recurrence with Multi-Head Self-Attention. Tokens query all other tokens simultaneously to map contextual relationships, solving long-range dependencies.

  • Causal masking for decoders
  • Scaled Dot-Product Attention
  • Stacked LayerNorm & FFN Blocks
